# Dataset

Place the official **AI4I 2020 Predictive Maintenance Dataset** CSV in this directory.
The project expects the CSV columns from UCI dataset 601 and does not modify the raw file.

Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)

Citation: Matzka, S. (2020). *AI4I 2020 Predictive Maintenance Dataset*. DOI: 10.24432/C5HS5C.
